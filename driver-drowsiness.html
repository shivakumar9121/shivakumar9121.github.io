CASE STUDY 01 / AI/ML · COMPUTER VISION

From pixels to predictions.

Driver Drowsiness Detection

A PyTorch image classifier connected to an OpenCV webcam workflow.

PythonPyTorchtorchvisionOpenCV

THE PROBLEM

How can an image-classification model be connected to a live camera workflow that produces an understandable drowsy or not-drowsy prediction?

I implemented a two-class classifier with a Darknet-53 backbone and attention module, then connected the model to image and webcam inference workflows. The project covers preprocessing, training, validation and prediction display.

ARCHITECTURE

  1. 01Image / frame
  2. 02RGB + resize
  3. 03Darknet-53
  4. 04Attention
  5. 05Two-class output

IMPLEMENTATION

Residual feature extraction

Convolutional blocks and residual connections form the Darknet-53 backbone. Global average pooling converts the feature map into the vector used by the final classifier.

Attention in the classifier

An attention module reweights the feature map before pooling. Although the class is named AttentionYOLOv3, its implemented output is image classification rather than bounding-box detection.

Camera-to-model integration

OpenCV captures a frame, converts BGR to RGB and passes it through the same resize and normalization steps used for inference. The predicted class is drawn on the video frame.

RESULT & NEXT STEPS

What the project demonstrates

The implemented result is a set of training and inference notebooks, including a local webcam prediction workflow. This portfolio does not claim independently verified accuracy or deployment in a real driver-safety system.

Engineering considerations

Training and inference must agree on image transforms, checkpoint architecture and class order. The current training notebook shares augmented transforms across randomly split training and validation subsets.

Use deterministic validation transforms, a subject-independent test set and tests across lighting and occlusion conditions. Temporal smoothing is a useful next step for camera predictions.

EXPLORE THE WORK

Implementation includes nthuddd.ipynb, predict.ipynb, liveprediction.ipynb and predictvideo.ipynb. The notebooks cover model training, image prediction, webcam inference and video input.
