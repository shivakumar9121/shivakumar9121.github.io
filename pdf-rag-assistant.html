PDF RAG Assistant

PDF question answering with hybrid retrieval, cross-encoder reranking and streamed answers with page citations.

PythonStreamlitChromaDBSentence TransformersBM25Groq

THE PROBLEM

Finding an answer across PDFs should lead back to the page that supports it.

I built a Streamlit application that accepts multiple PDFs, extracts their text and retrieves relevant passages for a question. The retrieved context is sent to a language model with instructions to cite the source filename and page.

ARCHITECTURE

  1. 01Extract + chunk
  2. 02Embed + index
  3. 03BM25 + vector search
  4. 04Rerank passages
  5. 05Stream answer

IMPLEMENTATION

Keep the source attached

PyMuPDF extracts text page by page. Character chunks retain the filename and page number, with overlap to preserve context across boundaries. BGE-small embeddings are normalized before indexing in ChromaDB.

Combine two retrieval signals

BM25 keyword search and semantic vector search each produce candidates. The implementation merges and deduplicates them, then uses a BGE cross-encoder to rerank passages and select the final context.

Connect retrieval to an interface

The Streamlit chat interface supports multiple uploads, session chat display and streamed responses. The OpenAI-compatible Groq API currently serves openai/gpt-oss-120b. The prompt asks for answers grounded in the supplied context and filename/page citations.

RESULT & NEXT STEPS

What the project demonstrates

An implemented document-question-answering pipeline connecting text extraction, embeddings, hybrid retrieval, reranking and an LLM API to a usable interface.

Current limits

Scanned image-only PDFs need an OCR stage. Prompted citations still require verification, and the retriever has no relevance threshold for rejecting weak matches. A separate evaluation experiment in the repository uses a different pipeline; its recorded scores are not presented as validation of this application.

Next improvements would add retrieval tests, explicit collection cleanup, relevance thresholds and evaluation against a reproducible document set.

EXPLORE THE WORK

Review notes_gpt/ingest.py, retrieve.py, chat.py and app.py for the extraction, retrieval, generation and interface implementation.
